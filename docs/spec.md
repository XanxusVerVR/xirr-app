# 目標

- 做出一個 XIRR 投資年化報酬率計算機

# 方法

- 用 angular 做出一個純靜態前端 XIRR 投資年化報酬率計算機

# 規格

- 請參考此網站的架構 https://www.laneto.co/xirr-calculator
- 只需實作期初部位, 資金進出記錄, 期末部位三個部分即可。其他說明欄都不用
- 一樣要有清除全部的功能
- 載入範例
    - 載入外幣範例不需實作，只需有一個叫載入範例即可
- 資金進出記錄可以拖曳每一列的日期
- 資金進出記錄可自動排序：送出計算後，發現日期順序不對，會自動依照日期排序
- 資金進出記錄要可以選擇複製某一筆：以減少重複輸入一樣的內容
- web上要有一個yaml code block: 當我不想用輸入表單的時候，可以在yaml輸入資料，一樣可以計算
- web上要說明yaml code block的資料格式範例
- 計算結果要有: 總投入金額, 總匯出金額, 當前總部位, 年化報酬率 (XIRR), 總報酬

# 名詞解釋

- XIRR: 是一種用來計算「不固定日期、多筆現金流」真實年化報酬率的數學方法。
