# P1 修正筆記：求解器過早判定收斂

- 修正日期：2026-09-13
- 對應審查項目：`docs/2026-09-12-code-review.md` 第 1 項（P1）
- 影響檔案：`src/app/core/xirr/npv.ts`、`src/app/core/xirr/solver.ts`、`src/app/core/xirr/solver.spec.ts`

## 根本原因

`solver.ts` 的收斂容許誤差由**未折現**的原始金額算出（`1e-9 x max|cf_i|`），卻拿去比對 `npv`——一個由**折現後**各項相加而成的值。`t_i` 以第一筆現金流的日期為基準，因此當最早一筆現金流的日期遠早於其餘現金流、且金額為 0 時，後面每一項都被 `(1+r)^t` 這個極大的因子除過，`npv` 的量級掉了好幾個數量級，容許誤差卻仍釘在 `max|cf_i|` 上。Newton 於是在利率離真解還很遠的地方就宣告收斂，並以「成功、無警示」的形式回傳錯誤的報酬率。

在誤判的根附近實測（期初 `0 @ 2000-01-01`、投入 `1000 @ 2024-01-01`、期末 `2000 @ 2024-12-31`）：

```
tolerance = 1e-9 x 2000 = 2.000e-6
r = 100.0000%  ->  NPV = 0.0000e+0    （真解）
r =  97.8520%  ->  NPV = 8.2919e-7    < tolerance  -> 誤判收斂
r =  90.0000%  ->  NPV = 1.0631e-5    > tolerance  -> 正確拒絕
```

同一個 `r = 97.8520%`，若時間基準改為 2024-01-01，NPV 為 1.0857e+1，會被正確拒絕——可見問題出在容許誤差與被比較量的量級不相稱，而非利率本身。

期初部位為 0 是規格明確允許的輸入（從零開始定期定額），因此這個缺陷從一般使用就能觸發。

## 與設計文件的偏離

設計文件 `docs/superpowers/specs/2026-09-12-xirr-calculator-design.md` §7 訂的收斂判準 `|NPV| < 1e-9 x max|cf_i|` **是錯的**：它用未折現的量去衡量折現後的殘差。本次刻意不照該條實作，程式碼中已於 `RELATIVE_TOLERANCE` 的註解註明偏離理由。

## 修改內容

1. `npv.ts` 新增匯出函式 `npvScale(cfs, rate)`：回傳 `Σ |cf_i / (1+rate)^t_i|`，也就是 `npv()` 在該利率下實際加總的那些項的量級。它與 `npv()` 共用同一個 `yearsFromStart` 與同一個 365 天分母，兩者不會各自漂移；和為 0 或非有限值時回傳 1，確保容許誤差不會退化成 0。
2. `solver.ts` 的 Newton 收斂條件改為 `|npv(cfs, rate)| < RELATIVE_TOLERANCE * npvScale(cfs, rate)`，且**每次迭代依當前利率重算**，不再由 `scaleOf(cfs)` 一次算定。此判準對時間基準不變：在最前面插入一筆金額為 0 的現金流，`npv` 與 `npvScale` 同比例縮放，比值不變。
3. 移除已無人使用的 `scaleOf`。
4. 步長停滯判準由絕對值 `|next - rate| < 1e-14` 改為相對值 `|next - rate| <= 1e-14 * max(|rate|, |next|)`。原本的絕對閾值是對一個自然量級為 `|rate|` 的量做比較，而本專案的極端案例中 `rate` 可達 1e109，該閾值在那種量級下永遠不可能成立。
5. **bisection 完全未動**——它以區間寬度收斂，不受容許誤差影響；而且在 Newton 現在會正確拒絕收斂時，它正是保底的那一層。兩處自適應擴張（右端無上限倍增、左端對 -1 的剩餘距離減半）與其警語註解原封不動。

## 容許誤差的選擇：1e-12

double 的相對精度約 2.2e-16；`npv` 是一個幾乎完全相消的和，其浮點誤差約為 `n x eps x Σ|項|`，對本專案的現金流筆數而言約 `1e-15 x npvScale`。取 `1e-12` 等於在這個雜訊樓地板之上留約三個數量級的餘裕：

- **實際可達成**：不會因為浮點雜訊而讓 Newton 永遠無法收斂（真的達不到時仍有 bisection 保底）。
- **足夠嚴格**：殘差降到這個比例時，對應的利率誤差已是機器精度等級。舊的 `1e-9` 表面上看起來嚴格，但它是拿去跟一個大得多的量（未折現金額）相比，實際上寬鬆得多。
